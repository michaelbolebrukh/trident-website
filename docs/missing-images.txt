Images still needed
===================

Every model image resolves locally. What remains is the blog: 24 featured
images, 34 inline images and one video, all of which lived only on the old
SiteGround server.

WHY THEY ARE UNREACHABLE NOW
  DNS for tridentmodular.com moved to Hostinger, so the old server can no
  longer be reached by name, and it resets TLS when addressed by IP
  (35.214.18.19). The .ua media library holds none of these 56 files.

HOW TO RECOVER THEM

  Best: the SiteGround account still exists. Site Tools -> File Manager ->
  public_html/wp-content/uploads/ — zip the folder and drop it in Drive or
  the repo. Full quality, covers everything including the video.

  Fallback: 27 of the 56 are in the Wayback Machine. This sandbox's network
  policy blocks web.archive.org downloads, but a browser can fetch them —
  the URLs below return the original file. Once the files are anywhere
  reachable (Drive folder shared like the garden renders was), everything
  wires itself in: the importer and templates already resolve any file that
  appears in the image map.
