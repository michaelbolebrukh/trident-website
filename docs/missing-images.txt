Images still needed
===================

Every model image now resolves locally. What remains is the blog.

BLOG FEATURED IMAGES  (24 of 24 posts)

  Every post's featured image was hotlinked from tridentmodular.com, which
  now answers image requests with a bot-protection challenge, so none of
  them came across. The posts render without one rather than showing a
  placeholder, but a blog with no imagery is a weak page.

  The images are at:
    SiteGround Site Tools -> File Manager
    public_html/wp-content/uploads/

  Spread across month folders rather than one place, so the simplest fix by
  far is to turn off bot protection in Site Tools -> Security for ten
  minutes and say so — scripts/fetch-images.mjs then pulls every one
  automatically, using the paths already recorded in src/data/posts.json.

  Failing that, a zip of wp-content/uploads/ dropped into Drive or the repo
  works just as well.
